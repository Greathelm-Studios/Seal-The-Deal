# Decisions

**Status:** Current · **Last updated:** 2026-11-22

Technical and process decisions, newest first. One line each: date, what, who, link.
Design decisions live in [GDD.md](GDD.md), not here. Rules: [AGENTS.md](../AGENTS.md) §12.

- 2026-11-22 — Generated floors are a pure function of (match seed, floor number): rooms and corridors on the kit's 4 m grid, checked on a 0.5 m walk map, regenerated with the next attempt number until every check passes. The checks are part of the function, so every machine lands on the same attempt and nothing about a floor is sent. Random numbers are integer-only (our own xorshift), so no machine's float maths can change a layout. Hand-made floor templates picked by seed were rejected: Harvey asked for generated floors. — Harvey's agent (technical call, see owner-defers note). [systems/FLOOR_GEN.md](systems/FLOOR_GEN.md).
- 2026-11-22 — Each floor of the floor race has two lifts from floor 2 up: the arrival lift the briefcase firm steps out of, and the hidden exit lift. A floor does not depend on the floor below, so the arrival lift is not where the last exit lift stood; the ride is a loading screen. — Harvey's agent (technical call). [systems/FLOOR_GEN.md](systems/FLOOR_GEN.md).
- 2026-11-15 — Voice chat keeps our own capture, packets and playback but now compresses with Opus (Concentus 2.2.2, plain C#) and cleans the microphone with RNNoise 0.1.1 (a native DLL for 64-bit Windows, built from Xiph's source). Both are BSD-licensed vendor code in `Assets/Plugins/`, each behind one wrapper file; their licence texts must ship with the game. This replaces the ADPCM codec in the line below, which sounded poor. — Harvey ("For the compression, yeah go grab that", "Yes on the RNNoise"). [systems/VOICE.md](systems/VOICE.md).
- 2026-11-15 — Voice chat is our own: Unity's microphone, our own 4:1 speech compression (IMA ADPCM at 16 kHz, about 8 kB a second per talker) and FishNet broadcasts; the host passes a voice on only to players within earshot of the speaker. No Steam voice, no voice library, no service. Opus would be a third of the size but is a native library to ship. — Harvey ("make our own custom VOIP"), codec chosen by his agent. [systems/VOICE.md](systems/VOICE.md).
- 2026-11-13 — Integration: players start with the pistol only; the AR-15 is a floor-2 pickup; every match start resets everyone to that and full health. — Agent (integration default, Adam to confirm). [systems/INTEGRATION.md](systems/INTEGRATION.md).
- 2026-11-13 — Integration: a gun picked up goes to the weapon slots, never the hands; one already carried is refilled; with both slots full it replaces the gun in hand, which drops as a pickup; a new gun is not drawn automatically. — Agent (integration default, Adam to confirm). [systems/INTEGRATION.md](systems/INTEGRATION.md).
- 2026-11-13 — Integration: the briefcase and a carried item share one pair of hands ("hands full" otherwise); the briefcase wins F when both are in reach, a lobby desk, stand or mirror wins over both; F interact and G drop on every path, pad north and d-pad down. — Agent (integration default, Adam to confirm). [systems/INTEGRATION.md](systems/INTEGRATION.md).
- 2026-11-13 — Integration: a briefcase carrier can take and fire guns; a player carrying an item can neither fire nor take a gun; nobody fires in the lobby reception. — Agent (integration default, Adam to confirm). [systems/INTEGRATION.md](systems/INTEGRATION.md).
- 2026-11-13 — Integration: the lobby desk starts the match through `HostStartRun`; the Esc menu's start stays as a host shortcut labelled as skipping the desk; 8 s after a result everyone is brought back to reception empty-handed and the desk reopens. — Agent (integration default, Adam to confirm). [systems/INTEGRATION.md](systems/INTEGRATION.md).
- 2026-11-13 — Integration: the shared reception stands at street level beside the towers and counts as in play for the match; loot (both guns, the gadgets, a panel, chairs) is spawned by the host on floors 1–3 of both towers at the same spots after each tower build. — Agent (integration default, Adam to confirm). [systems/INTEGRATION.md](systems/INTEGRATION.md).
- 2026-11-12 — Match state is a few SyncVars sent on change (phase, the shared briefcase, each firm's checkpoint); the clock is worked out locally from the phase's start tick, never sent; a carried briefcase is hung on the carrier locally, never streamed. — Agent (technical call, see owner-defers note). [systems/MATCH.md](systems/MATCH.md).
- 2026-11-13 — The ragdoll chases animation clips (CC0 Quaternius library, retargeted in Blender, imported as Generic) instead of the hand-written procedural pose; this reverses the no-clips choice below. Still local to each client, nothing synced. — Alex. [systems/CHARACTER_ANIMATION.md](systems/CHARACTER_ANIMATION.md).
- 2026-11-13 — FishNet stays as the plumbing (connections, spawning, prediction); we do not write our own netcode stack. Where the game is unusual we add our own layer on top, one system at a time. A full replacement would need evidence from a real session and Adam's agreement. — Harvey, on his agent's recommendation. [systems/NETCODE.md](systems/NETCODE.md).
- 2026-11-12 — The player's body is an active ragdoll (rigidbodies and motorised joints chasing the procedural pose), run in a physics scene of its own so FishNet's re-simulation and the predicted capsule cannot touch it; local to each client, nothing synced. — Alex. [systems/CHARACTER_ANIMATION.md](systems/CHARACTER_ANIMATION.md).
- 2026-11-12 — Players are animated procedurally with no clips and no new package: a script poses the humanoid skeleton from the body's movement, local to each client, nothing synced. — Alex. [systems/CHARACTER_ANIMATION.md](systems/CHARACTER_ANIMATION.md).
- 2026-11-12 — Prop motion moves from one FishNet NetworkTransform per prop to Switchboard, a per-player byte-capped stream that favours nearby floors. Host authority is unchanged. The greybox prop prefabs use it from 2026-11-13; compiled, not yet seen from a client. — Harvey's agent (technical call, see owner-defers note). [systems/SWITCHBOARD.md](systems/SWITCHBOARD.md).
